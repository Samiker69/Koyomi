## 📋 План: Комплексный рефакторинг архитектуры обработчиков команд

**Обзор**: Унифицировать slash и префиксные команды, устранить 350+ строк дублирования, оптимизировать поиск (O(n·m) → O(1)), централизовать обработку. **Результат**: одиночный обработчик, кешированный индекс, переиспользуемые сервисы.

---

### **Фаза 1: Архитектурные сервисы** (3-4 дня)

Создать 5 новых сервисов, которые устранят дублирование:

1. **CommandValidationService** — единая логика кулдаунов и проверки отключения
   - Используется сейчас: 30 строк в messageCreate.js + 30 в interactionCreate.js

2. **CommandExecutionService** — выполнение с обработкой ошибок и логированием

3. **CommandLocalizationService** — один раз применить язык (копируется сейчас 5 раз)

4. **CommandErrorHandler** — единая обработка ошибок

5. **CommandIndexService** — кешированный индекс команд/субкоманд (O(1) поиск)

---

### **Фаза 2: Унификация обработчиков** (4-5 дней)

**interactionCreate.js** (~100 → 50 строк):
- Переписать с использованием сервисов
- Добавить обработку кнопок (nhentai, roleMenu, eval)
- Централизовать автодополнение

**messageCreate.js** (~200 → 80 строк):
- Использовать CommandIndexService для поиска (вместо O(n·m) цикла)
- Применить CommandLocalizationService
- Интегрировать CommandValidationService и CommandExecutionService

**Результат**: параллельная поддержка обоих типов команд без копипасты

---

### **Фаза 3: Оптимизация поиска** (2-3 дня)

- **CommandIndexService**: кеш субкоманд для быстрого поиска (вместо полного перебора)
- **DatabaseService**: LRU кеш настроек гильдии (5 мин TTL)
- **buildCommandOptions**: улучшение валидации типов (ATTACHMENT, ROLE permissions, CHANNEL visibility)

---

### **Фаза 4-7: Инфраструктура** (2-3 дня)

- **EventHandler**: явный порядок загрузки (убрать race conditions)
- **CommandHandler**: валидация при загрузке (autocomplete, структура)
- **config.json**: вынести hardcode (prefix, cooldown, defaults)
- **tests**: расширить coverage (индекс, валидация, опции)

### **Ключевые улучшения**

| Проблема | Решение | Выигрыш |
|----------|---------|---------|
| 350+ строк дублирования | Сервисы CommandValidation/Execution/Localization | -70% код |
| O(n·m) поиск субкоманд | CommandIndexService с Map кешем | O(1) вместо O(n·m) |
| Race conditions при загрузке | EventHandler с явным порядком | ✓ детерминировано |
| Захардкодированные значения | config.json | ✓ конфигурируемо |
| Копипаста локализации | CommandLocalizationService | ✓ один раз |
| Отсутствие валидации | Проверки при загрузке команд | ✓ ранее выявление |

### ⚠️ Ключевые решения

- **Двойная система**: поддерживать slash + prefix параллельно (slash удобнее, prefix гибче)
- **Постепенная миграция**: сервисы → обработчики → тесты (минимизировать регрессию)
- **Кеширование субкоманд**: 3-уровневая иерархия (команда → группа → субкоманда)
- **Единый entry point**: все взаимодействия через interactionCreate.js
