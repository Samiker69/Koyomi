### Сервисы
в чём суть? команды и ивенты - сборщики говна, а сервисы - обработчики говна.<br>
чтобы не срать 900 одинаковых строк (hi moderation.js), достаточно написать сервис, который сделает проверку прав, другой сделает работу с бд, а третий работает с наказаниями. команда/ивент лишь вернут то, что вернут сервис.

Другой пакетный менеджер - Bun. зачем? ну эээ, он быстрее, он умеет интерпретировать ts без трансляции в js.

### Что такое этот ваш [Bun](https://bun.com)
Для установки зависимостей:

```bash
bun install # bun i
```

для запуска файла/package скрипта:

```bash
bun run index.ts
```
